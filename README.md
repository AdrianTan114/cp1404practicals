## About CP1404 - Programming II

CP1404 teaches students important programming skills, concepts and best practices.
Such best practices can be found in
the [Programming Patterns](https://github.com/CP1404/Starter/wiki/Programming-Patterns) page.

- Always ask yourself, "Is this the best way? Is there a better way to do this?"
- Always follow naming conventions. They make the code readable and reduces misinformation.
- Make your code reusable and easily modifiable. Use functions, ensuring they follow the Single Responsibility
  Principle. Use constants instead of magic numbers.
